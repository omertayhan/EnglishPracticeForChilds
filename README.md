# EnglishPracticeForChilds

2. sınıf öğrencileri için İngilizce kelime pratiği web sayfası.

## Konular
Greetings, My Family, Colors, Numbers, Animals, Fruits, Toys, My Body, Clothes, Feelings, Classroom

## Modlar
- **Öğren:** kartlara dokun, telaffuzu dinle; "Hepsini göster" ile otomatik slayt
- **Quiz:** resimden kelime bul / sesten resim bul; seri (🔥) ve yıldız kazan
- **Harfler:** karışık harfleri sıraya dizerek kelimeyi yaz
- **Eşleştir:** hafıza kartları, resim ve kelimeyi eşleştir

## Ödül sistemi
Konu başına 1–3 yıldız, seviye çubuğu (Beginner → Super Owl), 2 yıldızda açılan çıkartma albümü. İlerleme tarayıcıda (localStorage) saklanır.
